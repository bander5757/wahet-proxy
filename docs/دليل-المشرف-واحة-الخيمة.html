دليل المشرف - برنامج واحة الخيمة

شرح مبسط لعمر كمدخل بيانات ومتابع للعمل اليومي من الجوال أو الكمبيوتر.

الهدف: تسجيل البيانات بوضوح، متابعة العملاء، وتنبيه بندر وابو فايز بأي شيء يحتاج قرار.
أهم قاعدة: لا تسجل أي مبلغ أو حركة بدون ملاحظة واضحة توضح السبب والمستلم أو العميل.

1. الدخول للبرنامج

  1. افتح رابط البرنامج.
  2. اضغط زر دخول.
  3. اختر حساب المشرف.
  4. اكتب كلمة المرور.
  5. إذا كان الجهاز خاص بك، فعّل حفظ الدخول حتى لا تحتاج تسجيل الدخول كل مرة.

2. الرئيسية

هذه الصفحة تعطيك نظرة سريعة على وضع المؤسسة.

  • راجع العروض والفواتير القادمة.
  • راجع المبالغ المسددة والمتبقية.
  • انتبه للتركيبات القريبة.
  • راجع التنبيهات المهمة للموظفين والسيارات.
  • إذا ظهر شيء يحتاج متابعة، افتح تبويبه وسجل الإجراء.

3. العملاء

هذا التبويب يعرض العملاء وعروض الأسعار والفواتير القادمة من دفترة.

  • ابدأ دائمًا بعروض الشهر الحالي.
  • العرض غير المؤكد يحتاج اتصال أو متابعة مع العميل.
  • إذا وافق العميل، غيّر حالة العرض إلى مؤكد.
  • إذا العميل اعتذر أو استغنى، غيّر الحالة حتى لا يبقى العرض مفتوحًا.
  • افتح تفاصيل العرض لمراجعة رقم العميل، الموقع، المدة، وتاريخ التركيب إذا كانت موجودة.
ملاحظة: إعدادات ربط دفترة خاصة ببندر فقط، لا تحتاج تعديلها.

4. المحاسبة

هذا التبويب لتسجيل الحركات المالية اليومية.

الحركات التي تسجلها

  • مصروف.
  • عهدة.
  • إيراد.
  • سلفة.
  • دين أو مبلغ متبقٍ.

عند التسجيل

  • اكتب المبلغ بدقة.
  • اختر الحساب: الرسمي أو الفرعي.
  • اكتب الشخص أو العميل المرتبط بالحركة.
  • اكتب ملاحظة واضحة: سبب التحويل، المستلم، ورقم الفاتورة إن وجد.
  • أرفق صورة الإيصال إذا كانت متوفرة.

5. المحاسب الذكي

هذا الجزء يساعد في مراجعة كشف البنك ومطابقة الحركات.

  • الأفضل رفع كشف البنك بصيغة CSV أو ملف نصي مرتب.
  • PDF يمكن حفظه للتوثيق، لكن التحليل الدقيق منه يحتاج تطوير إضافي لاستخراج الجدول.
  • التحليل يعطي مطابقة مبدئية وتقرير أسبوعي وتقدير أولي للضريبة.
تنبيه: لا تعتمد على المحاسب الذكي وحده للرفع الضريبي النهائي إلا بعد مراجعة بندر أو المحاسب الزائر.

6. التركيبات

هذا التبويب يعرض التركيبات القادمة.

  • أي فاتورة من دفترة تظهر ضمن التركيبات.
  • أي عرض سعر تم وضعه كمؤكد يظهر ضمن التركيبات.
  • راجع تاريخ التركيب، موقع العميل، رقم الجوال، والمدة.
  • إذا كانت البيانات ناقصة، راجع تفاصيل العرض أو حدّث ملاحظات دفترة.

7. الموظفين والسيارات

هذا التبويب للتنبيهات والمواعيد المهمة.

  • انتهاء الإقامات.
  • انتهاء رخص العمل.
  • صيانة السيارات.
  • تغيير الزيت.
  • أي تنبيه عام مثل موعد مراجعة أو تجديد أو مهمة إدارية.

عند إضافة تنبيه، اكتب اسم التنبيه، تاريخ التنبيه، وملاحظة واضحة.

8. المنافسات

هذا التبويب لمتابعة الفرص والمنافسات المناسبة لواحة الخيمة.

  • ركز على خيام أوروبية، خيم، خيمة أوروبية، وتجهيز فعاليات تحتاج خيام.
  • افتح رابط المصدر وراجع التفاصيل.
  • سجل القرار: مناسبة، غير مناسبة، أو تحتاج مراجعة.
  • إذا كانت مناسبة، بلغ بندر للمراجعة قبل التقديم.

9. التقارير

هذا التبويب لمراجعة الملخصات.

  • تقرير أسبوعي.
  • تقرير شهري.
  • ملخص المصاريف.
  • ملخص الإيرادات.
  • المبالغ المتبقية.

إذا ظهر رقم غير واضح، راجع مصدر الحركة قبل التعديل.

10. زر حركة سريع

زر + حركة مخصص للتسجيل السريع من الجوال.

  • استخدمه عند تسجيل مصروف أو حوالة أو عهدة أو إيراد.
  • اكتب ملاحظة قصيرة وواضحة.
  • أرفق الإيصال إذا توفر.

طريقة العمل اليومية للمشرف

  1. افتح الرئيسية وشوف التنبيهات والمهم اليوم.
  2. افتح العملاء وراجع عروض الشهر الحالي.
  3. تابع العروض غير المؤكدة مع العملاء.
  4. سجل أي مصروف أو عهدة أو حوالة فورًا من زر حركة.
  5. راجع التركيبات القادمة وتأكد أن بياناتها واضحة.
  6. بلغ بندر بأي رقم ناقص، عرض غير واضح، أو منافسة مناسبة.
